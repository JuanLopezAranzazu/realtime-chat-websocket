# Chat en tiempo real utilizando WebSockets

## Descripción

Este proyecto es un ejemplo de cómo implementar un chat en tiempo real utilizando WebSockets. El servidor está construido con Node.js, y utiliza la biblioteca `ws` para manejar las conexiones WebSocket. El cliente es una aplicación web simple que se conecta al servidor y permite a los usuarios enviar y recibir mensajes en tiempo real.

## Ejecución

Para instalar las dependencias necesarias, ejecuta el siguiente comando:

```bash
npm install
```

Luego, para iniciar el servidor, utiliza el siguiente comando:

```bash
npm start
```

Modo de desarrollo:

```bash
npm run dev
```
